# Working in this repository

## Language

Use **U.S. English** everywhere, always: app text (labels, buttons, messages), code comments,
identifiers you name, docs, changelogs, commit messages, pull request descriptions, design
files and mockups.

- color, not colour; catalog, not catalogue; favorite, not favourite; gray, not grey;
  canceled, not cancelled; labeled, not labelled; honor, not honour; center, not centre;
  organize/recognize/realize (-ize), not -ise; analyze, not analyse; license (noun and verb).
- Dates in U.S. style where written out ("November 23, 2026").
- Keep fixed spellings that aren't ours to change, such as HTML attributes (`aria-labelledby`)
  and names from third-party APIs or libraries.
