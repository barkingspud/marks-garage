# marks-garage
A collection of personal projects, experiments, tools, and random ideas spanning Agentic AI, HAM radio, photography, music, automotive tuning, electronics, and whatever else catches my attention. If it needs code to make it easier, smarter, or more fun, it may end up here.

## Projects

Each project is self-contained in its own folder, with its own README and
CHANGELOG.

| Project | What it does |
|---|---|
| [`moon-eclipse-stabilizer/`](moon-eclipse-stabilizer/) | Stabilizes shaky lunar eclipse timelapses — locks the moon to a fixed position, removes field rotation, skips cloud-obscured stretches. GUI + Windows installer, or CLI. |
